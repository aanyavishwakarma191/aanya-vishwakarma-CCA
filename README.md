# C++ CCA Programs

This repository contains C++ programs written as part of my CCA coursework.
The programs cover five topics: Arrays, Enum, Structure, Pointers, and Union.

The aim is to understand these concepts through simple programs and practical examples.

### 1. Arrays
- Program 1: Display Array Elements
- Program 2: Sum of Array Elements
- Program 3: Find the Largest Element
- Program 4: Calculate the Average of Array Elements

### 2. Enum
- Program 5: Days of the Week
- Program 6: Traffic Light System
- Program 7: Season Selection
- Program 8: Student Result

### 3. Structure
- Program 9: Student Details
- Program 10: Multiple Student Records
- Program 11: Area of a Rectangle
- Program 12: Employee Details

### 4. Pointers
- Program 13: Display Variable Address

### 5. Union
- Program 17: Basic Union Example
- Program 18: Character Using Union

## How to Run

1. Install a C++ compiler such as GCC.
2. Open the repository folder in Visual Studio Code.
3. Open the terminal in the directory containing the program.
4. Compile the program:

   g++ filename.cpp -o program.exe

5. Run the program in PowerShell:

   .\program.exe

Replace `filename.cpp` with the name of the source file you want to execute.

## Learning Objectives

- Understand array declaration and traversal.
- Learn to define and use enumerations.
- Store related data using structures.
- Understand pointers and memory addresses.
- Explore how unions share memory between members.
